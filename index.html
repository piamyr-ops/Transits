How to ride

Enter meaningful word associations to travel between stops. There is no timer. Wrong answers cost 10 maximum points, while hints cost 5. There is one new puzzle per day. Interchange requires a middle station before the final destination. Branch Line travels from the start to Destination A, returns automatically to the start, then travels to Destination B. Convergence brings Start A and Start B to the same destination, one after the other.

Example
MOON → NIGHT → OWL
  1. Three words per puzzle. Interchange: visit the middle word, then the final word. Branch Line: reach A from the start, return automatically to that same start, then reach B. Convergence: reach the shared destination from Start A, then reach it from Start B.
  2. No countdown. Invalid or repeated transfers cost 10 points; unfamiliar associations can be explained without a penalty. A Local hint reduces the maximum by 5 points. A creative link can be explained and saved locally without a creativity bonus.
  3. Referee: The built-in offline referee checks clear associations, meanings, wordplay, idioms, common contexts, and curated cultural links. If a connection seems valid but is unrecognized, explain why the words relate. Optional online checks may help when a connection is not in the offline pack.
  4. Scoring: Start with a 100-point ceiling. Shorter verified routes earn more; unusual but supported connections can add a modest creativity bonus. Wrong turns and hints lower the score ceiling. Daily and Practice are scored separately.
